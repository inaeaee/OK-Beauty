# OK Beauty 가격표 — 가격 강조형 70 × 40 mm (바코드 없음)

엑셀 → A4 인쇄용 PDF(실치수). 피그마 없이 바로 인쇄할 수 있는 경로입니다.

## 레이아웃
| 영역 | 내용 | 규칙 |
|---|---|---|
| 상단 | 브랜드 로고 | 높이 5 mm, 최대 폭 34 mm. `logos/<브랜드명>.svg` 없으면 브랜드명을 굵은 대문자로 표시 |
| | 제품명 | 최대 2줄. 2.9 mm에서 2.3 mm까지 자동 축소, 그래도 넘치면 `…` |
| 하단 | `MEMBER PRICE` + 취소선 기존가(오른쪽) | 기존가가 없거나 멤버십가 이하이면 숨김 |
| | 멤버십가 | 최대 16 mm 굵게. 통화기호·소수점 아래는 작게. 폭에 맞춰 자동 축소 |

A4 기본 배치는 2열 × 7행 = 장당 14개입니다. 가운데 정렬이고 점선은 재단선입니다. 마지막 장도 같은 위치에 찍혀서 재단 위치가 바뀌지 않습니다.

## 설치 (처음 한 번)
```bash
cd price-tag
npm install          # playwright
npm run setup        # openpyxl + 크롬(인쇄 엔진)
```

## 사용
```bash
python3 make_tags.py 가격표.xlsx -o out/가격표.pdf
```
- 엑셀 머리글: `제품명, 브랜드명, 기존가, 멤버십가, 수량, 통화` (영문 `Product Name, Brand, RRP, Member Price, Qty, Currency`도 인식)
- 수량: 비면 1장, 0이면 출력 안 함
- 통화: AUD/USD 등 → `$`, KRW → `₩`(소수점 없음), EUR `€`, GBP `£`, JPY `¥`. 비면 AUD
- 옵션: `--cols 2 --rows 7 --gap 0` (A4에 안 들어가면 오류), `--no-cutlines`, `--sheet 시트이름`
- 같은 이름의 `.html`도 함께 저장됩니다. 실행 결과에 나오는 `주의` 메시지와 `warnings` 목록(제품명이 잘린 행)을 확인하세요.

**인쇄할 때는 반드시 배율 "실제 크기(100%)"로 하세요.** "페이지에 맞춤"을 켜면 크기가 줄어듭니다.

## 로고 추가
`logos/` 폴더에 브랜드명을 소문자-하이픈으로 바꾼 파일명으로 넣습니다.
예: `Beauty of Joseon` → `logos/beauty-of-joseon.svg`. svg, png, jpg, webp 모두 가능합니다.
